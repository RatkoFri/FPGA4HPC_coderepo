# FPGA4HPC_coderepo
Code repo for workshop FPGA4HPC conducted by CChip.si and EuroCC Slovenia [^1]

This repository contains code samples, which we will use during the workshop on FPGA programming with OpenCL and XRT.

## Installation
Download the code using:

```console
$ git clone https://github.com/RatkoFri/FPGA4HPC_coderepo.git
```

and move to subdirectory:

```console
$ cd FPGA4HPC_coderepo
```
